# Hover Translate language packs

Downloads only. Each zip is one language → English translation model for Hover Translate: Helsinki-NLP
**Opus-MT** (CC-BY 4.0, by Jörg Tiedemann and the Language Technology Research Group, University of Helsinki),
converted to CTranslate2 int8.

Hover Translate downloads a pack from the **Releases** of this repository when someone installs or adds a
language, and installs it only if it matches the SHA-256 checksum built into the app (`packs/models-index.json`).
The packs are built by the `models` workflow of the (private) application repository.
